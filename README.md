# Tanya’s Birthday

Адаптивный сайт по предоставленному PDF. Графика сохранена из авторского макета в WebP. На мобильных устройствах добавлены читаемые текстовые блоки.

Локальный запуск из этой папки:

```sh
python3 server/reserve.py --port 4173 --static dist --data reservations-local.json
```

Открыть http://localhost:4173. Эта команда поднимает и сайт, и API броней.

Место и время указаны в блоке с датой и прямо на розовой карточке (`.card-text` в `dist/index.html`). Для изменения текста редактируйте `dist/index.html`, стилей — `dist/style.css`.

Надписи в иллюстрациях являются частью исходного дизайна. Для изменения этих надписей потребуется обновить соответствующие изображения в `dist/assets/`. Читаемые мобильные тексты находятся в HTML.

При входе посетитель вводит имя и выбирает обращение. Автомат запускается только вручную: ручкой справа. Слоты выпадают на 777 и открывают персональное приглашение. Автозапуска при прокрутке нет. Ручка справа запускает автомат повторно. Имя хранится только в sessionStorage этого браузера. Анимации учитывают настройку уменьшения движения.

На каждом экране есть отдельные декоративные эффекты: мерцающие звёзды, плавающие масти и сердечки. Элементы плавно реагируют на движение мыши, касание создаёт вспышку.

Анимации: шторки открываются после ввода имени, затем летит конфетти. Экраны появляются при прокрутке, есть параллакс, след из искр за курсором и вспышки по клику. На первом экране прожекторы, падающие звёзды и пузырьки в бокале. У автомата бегут огни, на джекпот сыплются конфетти и монеты. Карточка с датой показывает обратный отсчёт до праздника. На экране Dress code мигает неоновый заголовок и срабатывают вспышки фотокамер. В вишлисте клешня достаёт подарки из кучи сердечек. При настройке «уменьшить движение» всё это отключается.

Дата и время для обратного отсчёта задаются константой `partyStart` в `dist/app.js`. Когда станет известно время праздника, поменяйте её.

## Вишлист и брони

Подарки перечислены в `dist/wishlist.json`: `id`, название, ссылка, картинка и (необязательно) цена `price`, которая показывается в «Твоих бронях». Клешня по очереди достаёт подарки. Рядом с подарком появляются название со ссылкой и кнопка «Бронь». После подтверждения бронь закрепляется за именем гостя, и другие гости этот подарок больше не видят. Свои брони гость видит под вишлистом и может их отменить, но только в том же браузере.

Брони хранит `server/reserve.py` (Python, без зависимостей). На сервере он работает как служба `server/tanyabirthday-api.service` на 127.0.0.1:8091, а nginx проксирует на него `/api/`. Кто что забронировал, записано в `/var/lib/tanyabirthday/reservations.json`.

У подарков с `"split": true` (сейчас это Лабубу) есть кнопка «Разделить оплату». Гость оставляет имя и контакт, а другие гости видят, кто уже хочет скинуться на этот подарок, и списываются сами. Заявки хранятся в `/var/lib/tanyabirthday/splits.json`. Чтобы снять бронь вручную, удалите запись из этого файла.
