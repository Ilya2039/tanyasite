# Tanya’s Birthday

Адаптивный сайт по предоставленному PDF. Графика сохранена из авторского макета в WebP. На мобильных устройствах добавлены читаемые текстовые блоки.

Локальный запуск из этой папки:

```sh
python3 -m http.server 4173 --directory dist
```

Открыть http://localhost:4173.

Место и время пока не заполнены; подарки пока не добавлены. Для изменения текста редактируйте `dist/index.html`, стилей — `dist/style.css`.

Надписи в иллюстрациях являются частью исходного дизайна. Для изменения этих надписей потребуется обновить соответствующие изображения в `dist/assets/`. Читаемые мобильные тексты находятся в HTML.

При входе посетитель вводит имя и выбирает обращение. Автомат запускается только вручную: ручкой справа. Слоты выпадают на 777 и открывают персональное приглашение. Автозапуска при прокрутке нет. Ручка справа запускает автомат повторно, кнопка внизу позволяет изменить имя. Имя хранится только в sessionStorage этого браузера. Анимации учитывают настройку уменьшения движения.

На каждом экране есть отдельные декоративные эффекты: мерцающие звёзды, плавающие масти и сердечки. Элементы плавно реагируют на движение мыши, касание создаёт вспышку.

Все пять экранов содержат многослойную непрерывную анимацию: плавное движение графики, вращение и мерцание частиц, движение света. Кнопка запуска внутри экрана удалена, казино запускается ручкой справа.
